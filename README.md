mend applies the edits AI models write — unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON text-editor calls — to a tree of files, matching lines at three whitespace tiers and writing every change or none. SPEC.md is the contract.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
node check.ts <practice.json>   # run the practice checks
```
